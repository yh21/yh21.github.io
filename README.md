# yh21.github.io

Personal blog and portfolio of Yunhyung Chang (장윤형): https://yh21.github.io

Built with [Astro](https://astro.build), Tailwind CSS and TypeScript, based on the [Astro Nano](https://github.com/markhorn-dev/astro-nano) theme (MIT).

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Start local dev server at `localhost:4321`  |
| `npm run build`   | Type-check and build the site to `./dist/`  |
| `npm run preview` | Preview the build locally                   |
| `npm run lint`    | Run ESLint                                  |

## Deployment

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
